# Aplikasi Manajemen Toko Fashion (TSM)

Aplikasi berbasis **Go (Golang)** yang dirancang untuk membantu pengelolaan data produk pada sebuah toko Kecantikan. Aplikasi ini merupakan program berbasis terminal (CLI) yang menyediakan fitur manajemen produk, pencarian, pengurutan, rekomendasi produk, serta laporan penjualan.

Proyek ini dibuat untuk memenuhi **Tugas Besar Mata Kuliah Algoritma dan Pemrograman II**.

## 🚀 Fitur Utama

Aplikasi ini mengimplementasikan konsep **Array of Struct**, **Pointer**, **Searching**, dan **Sorting** dalam bahasa Go.

### 📦 Manajemen Produk (CRUD)
- **Create** – Menambahkan produk baru dengan ID otomatis.
- **Read** – Menampilkan seluruh daftar produk dalam bentuk tabel.
- **Update** – Mengubah informasi produk yang sudah ada.
- **Delete** – Menghapus produk berdasarkan ID.

### 🔍 Pencarian Produk (Searching)
- Mencari produk berdasarkan **ID** menggunakan **Binary Search**.
- Mencari produk berdasarkan **Nama** menggunakan **Sequential Search**.

### 📊 Pengurutan Produk (Sorting)
- Mengurutkan produk berdasarkan **Harga**, **Stok**, atau **Nama**.
- Mendukung pengurutan **Ascending** dan **Descending** menggunakan algoritma **Selection Sort**.

### ⭐ Rekomendasi Produk
- Menampilkan rekomendasi produk berdasarkan kategori atau kriteria tertentu.

### 📈 Laporan Penjualan
- Menampilkan data penjualan produk.
- Menampilkan total penjualan.
- Menampilkan produk terlaris.

### ✅ Validasi Input
- Validasi setiap masukan pengguna.
- Menampilkan pesan **Success**, **Warning**, dan **Error** untuk meningkatkan pengalaman pengguna.
